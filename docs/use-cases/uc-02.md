# UC-02 — Dev watches the runtime self-heal (UF-03)

**Persona:** Dev — a generated tool starts failing days after conversion; the
repair agent must fix it with no human action.
**Goal:** exercise the F-030 self-heal loop: error capture → threshold →
patch → static gate → judge → smoke replay → hot swap, with a full audit trail.

## Commands

```bash
./scripts/test-uc-02.sh            # automated use-case script

# Manual equivalents:
uv run pytest -q tests/integration/test_repair.py
# then drive a heal with stub seams against a throwaway data dir
# (see scripts/test-uc-02.sh for the full inline driver)
```

## Expected output (excerpt)

```
tests/integration/test_repair.py .......                          [100%]
7 passed in 1.4s
PASS: first failure captured as repair_incident state=healing (below threshold)
PASS: threshold reached -> repair attempt heals; incident state=healed
PASS: hot swap: the patched adapter serves the call
PASS: audit trail records captured + healed repair events
```

Incident rows live in `repair_incidents` (states `healing` → `healed`); the
audit JSONL records `"event": "captured"` and `"event": "healed"` entries.
The dedicated pytest module additionally covers judge-blocked rollback
(byte-for-byte restore), the 3-strikes circuit breaker (quarantine +
`TOOL_DISABLED`), console re-enable, and degraded-mode rollback.

## What verifies what

- `repair_incidents` row states → capture + eligibility threshold (2 same-class failures / 10 min).
- Patched dispatch result → hot swap via `registry.refresh_module`, version chain parented to the broken version.
- Audit grep → every repair event lands in the audit ledger (AC-F030-03).

## Troubleshooting

See [docs/quickstart.md](../quickstart.md). If heal loops roll back, check the
judge seam and the sandbox spawn check via `uv run protocol-x-tool-mcp doctor`.
