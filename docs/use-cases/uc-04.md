# UC-04 — Petra: team deploy

**Persona:** Petra (platform engineer) — runs shared agent infrastructure for a
team: tokens, ACLs, policy presets, right-sized hosts.
**Goal:** prove the deployment building blocks: hashed bearer tokens with
per-tool ACLs (analysts never reach `http_get`), the `strict` preset disabling
the `http_*` tools at the registry, a green pre-flight `doctor`, and
env-override sizing (F-014, F-032, F-035, F-038).

## Commands

```bash
./scripts/test-uc-04.sh            # automated use-case script

# Manual equivalents:
export PROTOX_TOKENS="uc04-analyst,uc04-admin"
export PROTOX_TOOL_ACL='{"uc04-analyst": ["csv_info", "csv_read", "csv_filter", "csv_aggregate"]}'
uv run protocol-x-tool-mcp doctor --quick
PROTOX_POLICY_PRESET=strict uv run protocol-x-tool-mcp serve --transport http   # http_* gone
```

## What verifies what

- `TokenStore.check_acl` + dispatch with the analyst token context → `TOOL_NOT_PERMITTED` before any network work (F-014; tokens stored as SHA-256).
- Tokenless `POST /mcp` → 401 (auth middleware), `/health` stays open.
- `PROTOX_POLICY_PRESET=strict` → the four `http_*` tools are absent from the registry (34 → 30 tools).
- `doctor --quick` → green pre-flight with tokens/ACL in the environment.
- `profile_for_settings` with `PROTOX_CPUS/MEMORY/WORKER_POOL` → overrides applied **and reported** (AC-F038-03).
