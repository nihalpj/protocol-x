# UC-05 — Sam: security audit battery

**Persona:** Sam (security reviewer) — sign-off must rest on evidence, not trust.
**Goal:** run the repeatable verification path: the pytest security +
adversarial suites, then live probes of the three trust boundaries — the SSRF
guard, workspace confinement, and keyless workers (INV-1…8, F-008, F-033).

## Commands

```bash
./scripts/test-uc-05.sh            # automated use-case script

# Manual equivalents:
uv run pytest -q tests/security tests/adversarial
# live probes (SSRF block, path escape, keyless worker env) — see the
# inline driver in scripts/test-uc-05.sh
```

## Expected output (excerpt)

```
tests/security tests/adversarial 41 passed in 5s
PASS: SSRF guard blocks http_get to 127.0.0.1 (SSRF_BLOCKED)
PASS: SSRF guard rejects non-http schemes (file://) (SSRF_BLOCKED)
PASS: workspace rejects '..' path escapes (VALIDATION_ERROR)
PASS: workspace rejects absolute paths outside the root (VALIDATION_ERROR)
PASS: worker env is keyless (7 scrubbed vars, no configured secrets, AC-F033-01)
```

The pytest half covers the full SSRF battery (private/loopback/link-local/
reserved/multicast, redirect chains re-validated per hop, scheme rejection,
`ALLOWED_HOSTS` semantics) plus the adversarial judge corpus (every
known-violating adapter scores `blocked`; judge outage fails closed).

## What verifies what

- `http_get` to `http://127.0.0.1/` → `SSRF_BLOCKED` before any connect (loopback refusal).
- `file:///etc/passwd` → `SSRF_BLOCKED` at the scheme allowlist.
- `csv_info` with `../outside.csv` / `/etc/passwd` → `VALIDATION_ERROR` (workspace confinement, INV-5).
- `SubprocessRunner().worker_env()` with a configured `PROTOX_SECRETS` secret → the secret appears nowhere (AC-F033-01: workers are keyless by construction).
