# UC-06 — Polyglot (npm) package conversion — v1.1 scope

**Persona:** Dev — *"convert `<package>` into tools"* across ecosystems.
**Goal:** wrap an **npm** package into sandboxed MCP tools (F-036 polyglot
backends: npm → Go → Rust, identical sandbox + governance per backend).

## Status: green-skip

Polyglot conversion is **v1.1 scope** and is not implemented in v1.0. The
use-case script prints the skip line and exits 0 so the suite stays honest
about what ships today:

```bash
./scripts/test-uc-06.sh
# SKIP: uc-06 polyglot conversion is v1.1 scope
# PASS: uc-06 green-skip (F-036 npm backend lands post-v1.0)
```

## What ships in v1.0 instead

- Python-only converter (`protocol-x-tool-mcp convert <pkg>`, F-029) — see [UC-01](uc-01.md).
- The adapter contract already carries a `backend` field (`python` today) so
  npm/Go/Rust adapters plug into the same registry, sandbox, and judge gates.

## Troubleshooting

See [docs/quickstart.md](../quickstart.md). For v1.0, wrap Python packages via
[UC-01](uc-01.md); npm conversion lands on the v1.1 release train.
