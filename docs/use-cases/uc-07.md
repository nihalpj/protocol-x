# UC-07 — Degraded mode (no Token Factory key)

**Persona:** any operator installing without model credentials — degraded mode
is a first-class state, never a silent half-install (E-20).
**Goal:** prove that with `PROTOX_TF_API_KEY` unset the deployment still works:
`doctor` exits 0 with the token-factory check **WARN**, the 34 launch-core
tools stay fully live, and every agent feature fails closed.

## Commands

```bash
./scripts/test-uc-07.sh            # automated use-case script

# Manual equivalents:
unset PROTOX_TF_API_KEY
uv run protocol-x-tool-mcp doctor          # full mode; exit 0 with WARN
uv run protocol-x-tool-mcp serve --transport stdio   # 34 tools over tools/list
```

```
PASS: agent features disabled without a key (E-20)

```

## What verifies what

- `doctor` exit 0 + `WARN` line → yellow is not red; the messaging tells the operator exactly what is off and how to fix it (F-035).
- 34 tools from `AppContext.registry.list_tools()` → the full launch core is live (same catalog a stdio `tools/list` answers).
- `agent_features_enabled` False, `production_judge` → `None`, default judge verdict `blocked` → nothing can merge without the judge (E-5/INV-6).
