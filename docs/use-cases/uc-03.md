# UC-03 — Dana: analyst CSV flow

**Persona:** Dana (data analyst, light coder) — wants answers from CSVs without
writing pandas code.
**Goal:** drop a CSV into the workspace and answer real questions through the
`csv_*` tools: inspect, page, filter, aggregate — with limits stated and
oversized results saved as workspace files (F-010, F-005, F-020).

## Commands

```bash
./scripts/test-uc-03.sh            # automated use-case script

# Manual equivalent (seeds the workspace, then one dispatch per question):
source scripts/test-setup.sh       # fresh throwaway data dir + workspace
uv run python tests/fixtures/make_big_csv.py "$PROTOX_WORKSPACE/sales.csv"
cp samples/sample.png "$PROTOX_WORKSPACE/"
uv run python - <<'EOF'
import os
from server.app import AppContext
from server.config import Settings
ctx = AppContext(Settings())
print(ctx.dispatch("csv_info", {"path": "sales.csv"})["result"]["data"]["rows"])
print(ctx.dispatch("csv_filter", {"path": "sales.csv", "column": "col0",
                                  "op": "eq", "value": "g3"})["result"]["data"]["rows"])
ctx.store.close()
EOF
```

## Expected output (excerpt)

```
PASS: csv_info rows=20000 (got 20000)
PASS: csv_info reports columns col0..col9
PASS: csv_read limit=5 pages the rows and reports truncated:true (F-020 boundary)
PASS: csv_filter col0==g3 keeps 2000 rows (got 2000)
PASS: filter result saved into the workspace (out/…-filtered.csv, got out/<uuid>-filtered.csv)
PASS: result carries a protox-workspace:// resource ref (F-005)
PASS: csv_aggregate spans 10 groups (got 10)
PASS: every group aggregates exactly 2000 rows
PASS: sample.png answers via image_info (640x480)
```

Note: the brief's `csv_preview` does not exist — the read tool is `csv_read`
(`limit` 1–5000 rows per call, `offset` for paging, `truncated:true` signals
more pages).

## What verifies what

- `csv_info` / `csv_read` → whole-file inspect + boundary-inclusive paging (F-020).
- `csv_filter` → whitelisted ops only (never query/eval), result persisted to `out/` with a `protox-workspace://` resource ref (F-005).
- `csv_aggregate` → grouped `sum/mean/min/max/count` over explicit columns.
